# Prometheus — Environmental Monitoring System

Prometheus is a web-based environmental monitoring system designed to visualize sensor data from connected hardware through data platforms such as ThingSpeak.

The website brings environmental readings together in an interface featuring graphs, charts, and map-based monitoring. Its purpose is to make collected data easier to view and understand.

## Features

- **API integration** — Fetch sensor readings from compatible platforms such as ThingSpeak when configured.
- **Data visualization** — Display environmental readings using graphs and charts.
- **Map-based monitoring** — Visualize monitoring locations and related information.
- **Hardware data support** — Designed to work with data supplied by connected environmental sensors through a compatible platform.
- **Web-based interface** — Access monitoring visualizations through a browser.

## How It Works

1. Environmental sensors collect readings through connected hardware.
2. The hardware sends data to a compatible data platform, such as ThingSpeak.
3. The website retrieves available readings through the platform's API when configured.
4. The interface presents the retrieved information through graphs, charts, and maps.

The actual data displayed depends on the hardware, data source, API configuration, and features enabled in the application.

## Important Clarification

Prometheus is an **environmental monitoring and data visualization system**, not an AI wildfire prediction system. It does not automatically predict fires. Its role is to display available environmental data so users can observe and interpret the readings.

## Technologies

The project uses web technologies for its interface and data visualization. Actual dependencies and integrations depend on the implementation in this repository.
